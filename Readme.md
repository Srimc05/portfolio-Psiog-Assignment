# Sriii Portfolio Website

A modern, responsive developer portfolio built with pure HTML, CSS, and JavaScript.

This portfolio showcases my projects, technical skills, and design philosophy with a clean, high-performance frontend architecture.

---

## Live Demo

deployed link here: https://portfolio-ten-coral-20.vercel.app/

---


## Features

* Responsive design for desktop, tablet, and mobile
* Sticky announcement banner
* Premium hero section with custom typography
* Projects showcase with interactive cards
* About section with:

  * Tech stack
  * Stats
  * What I do timeline
  * Social links
* Custom cursor inspired by Figma
* Smooth scrolling and subtle animations
* Clean component-based file structure
